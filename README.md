🌍 Global Population Analytics Dashboard | Google Cloud BigQuery • Power BI
Project Overview
This project demonstrates an end-to-end cloud-based analytics solution using Google Cloud Platform (GCP), BigQuery, and Power BI to analyze global population data. The project uses two CSV datasets that were initially uploaded to Google Cloud Storage/BigQuery, where the data was stored and queried using BigQuery SQL. The BigQuery database was then connected to Power BI to develop an interactive dashboard for visualizing population trends and demographic insights.
The dashboard enables users to explore population distribution, growth patterns, demographic statistics, and country-level comparisons through interactive visualizations and filters. This project showcases the integration of cloud data warehousing with modern business intelligence tools to transform raw datasets into actionable insights.
Project Workflow
Step 1: Data Upload
Uploaded the two CSV datasets to Google Cloud Platform.
Loaded the datasets into BigQuery for cloud-based storage and querying.
Step 2: Data Processing
Created datasets and tables in BigQuery.
Queried and prepared the data using BigQuery SQL.
Structured the data for efficient analysis and reporting.
Step 3: Data Visualization
Connected Power BI directly to the BigQuery database.
Built interactive dashboards with charts, KPIs, maps, and filters.
Designed reports to analyze population trends and demographic indicators.
